# Requests

Срез 7 — интерфейс студенческих заявок на типизированных демонстрационных данных frontend. API и предметных таблиц пока нет; сохранение и интерфейс обработки сотрудника относятся к срезу 8. Будущий серверный модуль регистрируется через IAppModule/AppModules, а не через Program.cs. Серверные выборки должны ограничиваться доверенными UniversityId и StudentId.
