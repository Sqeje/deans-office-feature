# Requests

Модуль владеет локальными заявками студента и неизменяемой историей обработки. Регистрация через RequestsModule/IAppModule в AppModules. UI: /student/requests?view=create и ?requestId=UUID; /staff/requests и ?requestId=UUID.

API: GET/POST /api/requests/student, GET /student/{id}, GET /student/summary (204, если заявок нет); GET /staff/groups, GET /staff/summary (число заявок со статусом `submitted` или `in_review` по группам сотрудника), GET /staff?groupId=UUID, GET /staff/{id}, POST /staff/{id}/status. Все пути относительно /api/requests. DTO и RequestStatus публикуются через OpenAPI; клиент генерируется штатной командой.

Список сотрудника ограничивается разрешённой группой через AccessGuard и включает ФИО студента из StudentDirectory для этой группы и университета. Выборка имён для списка не принимает StudentId или UniversityId от клиента.

Создание принимает operationId (UUID) и input с kind из каталога ниже. Для справок нужны place 1–200 и copies 1–5; для обращения — reason 1–2000; для формы с периодом дополнительно start/end (календарные даты). Пробелы по краям удаляются; поля другой формы запрещены. Повтор operationId того же студента/вуза с тем же нормализованным содержимым возвращает прежнюю заявку; с другим — 409. UI сохраняет ключ незавершённой отправки в query operationId, без содержания заявки. При обновлении страницы поля нужно заполнить повторно; повтор отправки по этому URL сохраняет ключ. Новый переход «Создать заявку» начинает новую операцию.

Номер — глобальная последовательность PostgreSQL identity, пропуски допустимы. UUID — внутренний идентификатор. Группа фиксируется на момент подачи, поэтому перевод студента не переносит прежние заявки к другому сотруднику. UTC-моменты отображаются ru-RU/Europe/Moscow, периоды — календарные даты.

Статусы: submitted → in_review → ready → completed; из in_review также разрешён rejected. ready означает готовность к выдаче, completed — подтверждённое сотрудником получение документа или завершение обращения. completed и rejected не переоткрываются. Отклонение требует причины до 2000 символов. Смена принимает version для optimistic concurrency; конфликт — 409. Заявка, история, уведомление и общий аудит сотрудника сохраняются атомарно; общий аудит не содержит текста обращения.

Студент получает только свои данные в своём университете. Сотрудник требует requests.manage и AccessGuard по фактической группе заявки. Identity читается через IStudentDirectory. Мутации требуют CSRF. Демонстрационные записи из среза 7 используются только явными тестовыми фикстурами; production не подменяет ошибки API.

Каталог от 20.11.2026: RequestCatalog задаёт допустимые kind и форму полей; frontend/catalog.ts содержит соответствующие названия и пояснения. Три формы: certificate (место, экземпляры, необязательный комментарий до 2000 символов), period (причина, начало и конец), comment (причина без периода). Сервер и ограничения PostgreSQL отклоняют неизвестные виды и поля другой формы. Виды охватывают справки, академический отпуск, карты, мероприятия, изменение паспортных данных, стипендии, военную подготовку, оплату, отчисление, общежитие, индивидуальный график и социальные выплаты. Это обращения в учебный офис, а не автоматическое принятие административных решений.

DTO дополнен UpdatedAt; контракты регенерируются из OpenAPI. Миграция RequestCatalogAndCompletion меняет только ограничения, сохраняя существующие записи. Не откатывайте её при наличии новых видов или completed: предыдущая схема их не поддерживает.

При Demo:Enabled=true и Demo:Requests=true RequestDemoSeed добавляет только для student1@demo.invalid две заявки с историей (completed и ready) и одно непрочитанное уведомление на ready. Стабильные operationId исключают повторное создание и сохраняют ручные изменения. Compose включает этот сценарий по умолчанию; для запуска без примеров задайте Demo__Requests=false. Изолированные тесты включают примеры явно и не меняют рабочую БД.

Документы, вложения, отзыв/редактирование и внешние источники пока не реализованы. Пояснения не обещают отсутствующую загрузку файлов, скачивание официальной справки или неподтверждённые сроки.
