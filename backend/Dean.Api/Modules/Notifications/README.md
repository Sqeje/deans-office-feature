# Notifications

Срез 9 реализует только интерфейс студента на явно обозначенных типизированных демонстрационных данных frontend-модуля Notifications. Серверного модуля и API пока нет.

Сохранение прочтения, создание уведомлений по событиям и публикация объявлений относятся к срезу 10. Backend подключается через IAppModule и Infrastructure/AppModules, а не через предметный код в Program.cs. Персональные выборки должны ограничиваться доверенными UniversityId и StudentId; мутации требуют CSRF. Будущие DTO публикуются через OpenAPI.
