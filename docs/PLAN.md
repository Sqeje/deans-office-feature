# План фундамента

1. API net10.0: Identity, PostgreSQL, профиль только текущего пользователя, CSRF для всех небезопасных методов, OpenAPI.
2. React: общий API-клиент, вход, защищённый кабинет, профиль и отдельные страницы модулей.
3. Начальная миграция, идемпотентный seed с паролями из окружения, Compose с отдельной задачей инициализации БД.
4. Интеграционные тесты против PostgreSQL: два сеанса, изоляция, CSRF, выход, неверный пароль. CI собирает обе части.
5. Краткие инструкции запуска, границы модулей, правила миграций и шаблоны PR/среза.

Один deployable API и один DbContext уменьшают сложность V1. Папки и методы регистрации модулей изолируют изменения. Общие модели/миграции интегрируются последовательно. В production HTTPS завершается Caddy; API доступен только во внутренней сети.
