# Срез 2 — серверный вход, сеанс и профиль

Цель: два студента входят и видят собственные имена и профили; обновление сохраняет сеанс, выход закрывает кабинет.

Границы: существующий Identity и общий cookie-сеанс. Без регистрации, редактирования профиля, новых сущностей, миграций и реализации соседних разделов. Учебные сводки главной остаются явно демонстрационными.

Данные и API: PostgreSQL/Identity — источник истины. Существующие /api/identity/csrf, login, logout, session, me и DTO сохраняются. StudentId и UniversityId берутся из доверенного контекста; 401 означает отсутствие сеанса, 403 — запрет. Вход и выход требуют CSRF.

Интерфейс: DESIGN.md, существующие токены и компоненты. Загрузка, отказ доступа, ошибка с повтором; при ошибке выхода кабинет сохраняется. Блокировка повторной отправки. Проверка обеих оболочек, включая интегрированную успеваемость.
