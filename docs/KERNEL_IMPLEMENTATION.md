# Реализация Kernel

Согласованный объём: общий контекст/права и разделение аккаунта и профиля; явные точки регистрации модулей; единые ошибки и аудит; типизированные контракты трёх этапов интеграции; три оболочки frontend; миграция с сохранением студентов; тесты и инструкция расширения.

Порядок: 1. Security/Identity и миграция. 2. Modules/HTTP/Audit. 3. Integration contracts. 4. Frontend. 5. Проверки и документация.

Решение: текущий репозиторий без первого коммита, поэтому worktree не используется; работа в feature/kernel-foundation. История первоначальной миграции не переписывается. Никаких реальных источников, расписаний или операций сотрудников не реализуем.

Выполнены все пять этапов. Проверки: Release-сборка, PostgreSQL-тест переноса старого аккаунта и доступа, контрактные тесты интеграций, npm ci/build, браузерные сценарии трёх областей на 360 px. Ревью выявило гонку ответов сеанса: воспроизведена тестом и исправлена счётчиком поколений запросов. Также проверен выход на страницу входа при 401 профиля. Docker отсутствует, Compose и GitHub Actions локально не запускались.
